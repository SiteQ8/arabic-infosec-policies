## 1. الهدف / Purpose
تحديد إجراءات وضوابط التحكم في وصول المستخدمين للأنظمة والمعلومات، وضمان أن الوصول يقتصر على الأشخاص المخولين فقط وفقاً لمبادئ الأمان المعتمدة.

## 2. النطاق / Scope
تنطبق هذه السياسة على:
- جميع أنظمة المعلومات والتطبيقات
- جميع المستخدمين (موظفين، مقاولين، زوار)
- جميع أنواع الوصول (محلي، عن بُعد، إداري)

## 3. المبادئ الأساسية / Core Principles

### 3.1 مبدأ الحد الأدنى من الامتيازات / Principle of Least Privilege
- منح المستخدمين أقل مستوى من الصلاحيات المطلوبة لأداء مهامهم
- مراجعة دورية للصلاحيات وتقليلها عند الإمكان
- رفع الصلاحيات مؤقتاً عند الحاجة فقط

### 3.2 مبدأ الحاجة للمعرفة / Need-to-Know Basis
- الوصول للمعلومات بناءً على ضرورة العمل
- تصنيف المعلومات وتحديد مستويات الوصول
- منع الوصول العشوائي للمعلومات

### 3.3 مبدأ فصل الواجبات / Segregation of Duties
- توزيع المهام الحساسة على أكثر من شخص
- منع تضارب المصالح في الصلاحيات
- تطبيق الموافقات المزدوجة للعمليات الحرجة

## 4. إدارة هوية المستخدمين / User Identity Management

### 4.1 إنشاء حسابات المستخدمين / User Account Creation
**الإجراءات:**
1. طلب موقع من المدير المباشر أو صاحب الصلاحية
2. تحديد نوع ومستوى الوصول المطلوب
3. موافقة مسؤول الأنظمة أو مدير الأمان
4. إنشاء الحساب مع أقل صلاحيات مطلوبة
5. تسليم بيانات الوصول بطريقة آمنة

**المستندات المطلوبة:**
- نموذج طلب إنشاء حساب معبأ ومعتمد
- نسخة من هوية المستخدم
- تحديد الصلاحيات والأنظمة المطلوبة

### 4.2 تعديل الصلاحيات / Permission Modification
- طلب معتمد لتغيير الصلاحيات
- مراجعة الحاجة الفعلية للتغيير
- اختبار الصلاحيات الجديدة
- توثيق التغيير في سجل المستخدم

### 4.3 إلغاء الحسابات / Account Deactivation
**الحالات:**
- انتهاء خدمة الموظف (فوري)
- انتقال لقسم آخر (تعديل حسب الحاجة)
- إجازة طويلة (تعطيل مؤقت)
- اشتباه أمني (إلغاء فوري)

**الإجراءات:**
1. إشعار مسؤول الأنظمة فوراً
2. إلغاء جميع الصلاحيات والوصول
3. تأمين أو استرداد الأجهزة والبطاقات
4. نقل أو حفظ البيانات الشخصية حسب الحاجة

## 5. المصادقة / Authentication

### 5.1 كلمات المرور / Passwords

**متطلبات كلمة المرور:**
- طول لا يقل عن 12 حرف
- تتضمن أحرف كبيرة وصغيرة وأرقام ورموز
- عدم استخدام معلومات شخصية واضحة
- عدم إعادة استخدام آخر 12 كلمة مرور

**سياسات كلمة المرور:**
- تغيير كل 90 يوم للحسابات العادية
- تغيير كل 60 يوم للحسابات الإدارية
- قفل الحساب بعد 5 محاولات فاشلة
- مهلة زمنية 30 دقيقة قبل إعادة المحاولة

**حفظ كلمات المرور:**
- استخدام برامج إدارة كلمات المرور المعتمدة
- عدم كتابة كلمات المرور في أماكن ظاهرة
- عدم مشاركة كلمات المرور مع الآخرين

### 5.2 المصادقة متعددة العوامل / Multi-Factor Authentication (MFA)

**التطبيق الإلزامي:**
- جميع الحسابات الإدارية
- الوصول للأنظمة الحساسة
- الوصول عن بُعد
- حسابات البريد الإلكتروني

**العوامل المقبولة:**
- شيء تعرفه: كلمة مرور، PIN
- شيء تملكه: هاتف ذكي، رمز مميز
- شيء أنت عليه: بصمة، وجه، صوت

### 5.3 المصادقة الأحادية (SSO) / Single Sign-On
- تطبيق نظام SSO لتسهيل الوصول
- مراقبة جلسات SSO وتسجيل الأنشطة
- انتهاء الجلسة تلقائياً بعد عدم النشاط

## 6. التخويل / Authorization

### 6.1 نموذج التحكم في الوصول القائم على الأدوار / Role-Based Access Control (RBAC)

**تعريف الأدوار:**
- أدوار وظيفية محددة (محاسب، مدير، فني)
- أدوار تقنية محددة (مدير نظام، مشغل، مستخدم)
- أدوار مؤقتة للمشاريع الخاصة

**تصنيف الأدوار:**
- **أدوار إدارية عليا:** مدراء أقسام، مسؤولين تنفيذيين
- **أدوار إدارية متوسطة:** مشرفين، منسقين
- **أدوار تشغيلية:** موظفين، فنيين
- **أدوار ضيف:** متدربين، استشاريين

### 6.2 التحكم في الوصول القائم على الخصائص / Attribute-Based Access Control (ABAC)
- تحديد الوصول بناءً على خصائص المستخدم والموارد
- مراعاة الزمان والمكان والجهاز
- سياسات ديناميكية تتكيف مع السياق

### 6.3 مستويات التخويل / Authorization Levels

**مستوى الأنظمة / System Level:**
- مدير نظام كامل
- مدير نظام محدود
- مستخدم قياسي
- مستخدم مقيد

**مستوى التطبيقات / Application Level:**
- مدير تطبيق
- مستخدم متقدم
- مستخدم قياسي
- مستخدم قراءة فقط

**مستوى البيانات / Data Level:**
- وصول كامل للقراءة والكتابة
- قراءة وتعديل محدود
- قراءة فقط
- عدم وصول

## 7. مراقبة الوصول / Access Monitoring

### 7.1 تسجيل أحداث الوصول / Access Logging
**الأحداث المطلوب تسجيلها:**
- محاولات تسجيل الدخول (ناجحة وفاشلة)
- الوصول للملفات والأنظمة الحساسة
- تغيير الصلاحيات والأدوار
- استخدام الصلاحيات الإدارية

**معلومات السجل:**
- هوية المستخدم
- تاريخ ووقت النشاط
- نوع النشاط
- عنوان IP والموقع
- النتيجة (نجح/فشل)

### 7.2 مراقبة الأنشطة المشبوهة / Suspicious Activity Monitoring
- محاولات وصول متكررة فاشلة
- وصول من مواقع غير معتادة
- استخدام أنظمة في أوقات غير عادية
- محاولة الوصول لأنظمة غير مخولة

### 7.3 التقارير والتنبيهات / Reports & Alerts
- تقارير يومية للأنشطة الأمنية
- تنبيهات فورية للأنشطة المشبوهة
- تقارير أسبوعية لاستخدام الصلاحيات
- مراجعة شهرية شاملة للوصول

## 8. الوصول عن بُعد / Remote Access

### 8.1 متطلبات الوصول عن بُعد / Remote Access Requirements
- استخدام VPN معتمد من الشركة
- أجهزة معتمدة ومحدثة أمنياً
- مصادقة متعددة العوامل إلزامية
- تشفير البيانات المرسلة والمستقبلة

### 8.2 ضوابط الأمان / Security Controls
- فحص الأجهزة قبل الاتصال
- مراقبة حركة البيانات
- قطع الاتصال التلقائي عند عدم النشاط
- منع تنزيل البيانات الحساسة محلياً

### 8.3 أجهزة BYOD (Bring Your Own Device)
**الشروط:**
- تسجيل الجهاز في نظام إدارة الأجهزة المحمولة (MDM)
- تطبيق سياسات أمان الشركة
- إمكانية المسح عن بُعد عند فقدان الجهاز
- فصل بيانات الشركة عن البيانات الشخصية

## 9. الوصول الطارئ / Emergency Access

### 9.1 حسابات الطوارئ / Emergency Accounts
- حسابات خاصة للوصول عند الطوارئ
- كلمات مرور معقدة محفوظة في خزنة آمنة
- استخدام مؤقت ومراقب بصرامة
- تغيير كلمات المرور بعد كل استخدام

### 9.2 إجراءات الطوارئ / Emergency Procedures
1. تحديد طبيعة الطارئ ومستوى الاستجابة
2. موافقة من مسؤول أمن المعلومات
3. توثيق سبب ومدة الوصول الطارئ
4. مراقبة مكثفة لجميع الأنشطة
5. إلغاء الوصول فور انتهاء الطارئ
6. مراجعة شاملة بعد الطارئ

## 10. مراجعة الوصول / Access Review

### 10.1 المراجعة الدورية / Periodic Review
**جدولة المراجعة:**
- مراجعة ربع سنوية للصلاحيات العادية
- مراجعة شهرية للصلاحيات الإدارية
- مراجعة فورية عند تغيير المنصب
- مراجعة سنوية شاملة لجميع الوصول

**عملية المراجعة:**
1. إنتاج قائمة بجميع المستخدمين وصلاحياتهم
2. مراجعة مع المدراء المباشرين
3. تحديد الصلاحيات الزائدة أو غير المطلوبة
4. تعديل أو إلغاء الصلاحيات حسب الحاجة
5. توثيق نتائج المراجعة

### 10.2 مراجعة الحسابات المميزة / Privileged Account Review
- مراجعة أسبوعية لاستخدام الحسابات الإدارية
- تأكيد الحاجة المستمرة للصلاحيات المميزة
- مراقبة أنشطة الحسابات المميزة
- تدوير كلمات المرور للحسابات المشتركة

## 11. الأجهزة المحمولة والمتنقلة / Mobile & Portable Devices

### 11.1 إدارة الأجهزة المحمولة / Mobile Device Management (MDM)
- تسجيل إلزامي لجميع الأجهزة المحمولة
- تطبيق سياسات أمان موحدة
- إمكانية المسح والحظر عن بُعد
- مراقبة استخدام وموقع الأجهزة

### 11.2 التشفير والحماية / Encryption & Protection
- تشفير جميع البيانات المخزنة
- قفل الشاشة برقم سري أو بيومتري
- تحديث تلقائي للتطبيقات والنظام
- منع تنصيب تطبيقات من مصادر غير معتمدة

## 12. الامتثال والمراجعة / Compliance & Review

### 12.1 التدقيق الداخلي / Internal Audit
- مراجعة ربع سنوية لفعالية ضوابط الوصول
- اختبار عينات عشوائية للصلاحيات
- مراجعة سجلات الوصول والأنشطة
- تقييم مدى الالتزام بالسياسة

### 12.2 المخالفات والعقوبات / Violations & Penalties
**أنواع المخالفات:**
- مشاركة كلمات المرور
- محاولة الوصول غير المخول
- عدم اتباع إجراءات الأمان
- سوء استخدام الصلاحيات

**العقوبات التدريجية:**
1. تحذير مكتوب أولي
2. تدريب إلزامي على الأمان
3. تقييد الصلاحيات مؤقتاً
4. إجراءات تأديبية حسب سياسة الموارد البشرية
