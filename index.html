البدء السريع

ابدأ في دقائق

خطوات بسيطة لبدء استخدام السياسات في مؤسستك

تنزيل المستودع

قم باستنساخ المستودع على جهازك للبدء فوراً

# استنساخ المستودع git clone https://github.com/SiteQ8/arabic-infosec-policies.git # الدخول للمجلد cd arabic-infosec-policies # استعراض السياسات ls policies/

تخصيص السياسات

عدّل السياسات لتناسب مؤسستك

# استبدل اسم المؤسسة في جميع الملفات find policies/ -type f -name "*.md" \ -exec sed -i 's/\[اسم المؤسسة\]/شركتك/g' {} + # أو استخدم أداة npm npx arabic-infosec-policies customize \ --org "اسم مؤسستك" \ --sector "banking"

خطة التطبيق المرحلية

اتبع هذه الخطوات لتطبيق ناجح

# المرحلة 1: التقييم (الأسبوع 1-2) → مراجعة الوضع الحالي للأمن → تحديد الفجوات الأمنية → تحليل المخاطر # المرحلة 2: التخصيص (الأسبوع 3-4) → تعديل السياسات حسب المؤسسة → مراجعة الفريق القانوني → موافقة الإدارة العليا # المرحلة 3: التطبيق (الأسبوع 5-8) → تدريب الموظفين → التطبيق المرحلي → المراقبة والتحسين المستمر

التثبيت عبر npm

ثبّت الحزمة واستخدم أدوات سطر الأوامر

# التثبيت عالمياً npm install -g arabic-infosec-policies # أو محلياً في مشروعك npm install arabic-infosec-policies # عرض السياسات المتاحة arabic-infosec list # تصدير سياسة معينة arabic-infosec export --policy comprehensive --format pdf # تشغيل فحص الامتثال arabic-infosec audit --standard iso27001
